# 论文卡片

每篇论文一张卡片,文件名为 `<paper_id>.md`,与 `literature_matrix.csv` 的 `paper_id` 一一对应。

## 卡片模板(Day 4 起)

Day 3 卡片基于摘要;Day 4 起精读全文后改为 11 项模板,每一项**必须标注页码或章节**,论文未明确说明的内容标记为"论文未明确说明"。

```markdown
# <标题>

- **paper_id**: <与 literature_matrix.csv 一致>
- **作者**: <作者列表>
- **年份 / venue**: <年份> / <venue>
- **arXiv**: <链接>
- **精读日期**: YYYY-MM-DD(Day N)

## 1. 研究问题
## 2. 现有方法不足
## 3. 核心方法
## 4. 输入和输出
## 5. 训练方式
## 6. 推理方式
## 7. 数据集
## 8. 指标
## 9. 主要结果
## 10. 局限性
## 11. 与我的项目关系
```

> 页码 = PDF 物理页码,章节 = 论文章节号。
