# 新颖性审计

> 生成:2026-08-14(Day 5)。对照 `research/synthesis.md` 与 12 篇论文,检查本项目候选贡献是否重复已有工作、是否过度声称创新。
> **铁律**:不声称"首个新的 RAG 框架 / 新检索算法 / 新数据集 / 新基准"。创新只可能出现在"组合与评测方式",不在算法。
>
> 结论分级:🟢 文献明确支持 / 🟡 合理推断 / 🔴 尚未验证。

---

## 1. 候选贡献

**C1(实验型)** — 在小规模领域知识库(12 篇 RAG 论文)上,系统比较 **Dense / Hybrid / Hybrid+Reranker** 三种检索配置的检索质量(Hit@K、MRR)与生成质量(忠实度、双层引用正确率、拒答率)。

**C2(评估型)** — 以"**论文+章节双层引用正确率**"为北极星,在同一套评估集上同时测:检索质量、答案忠实度、引用正确率、真/误拒答率;并配**神谕检索(oracle)消融**把指标差异归因到"检索 vs 生成"。

**C3(分析型)** — 对失败案例做**分层归因**(解析 → 切块 → 检索 → 融合 → 重排 → 生成 → 引用 → 标注),给出错误类型分布与典型案例。

## 2. 与已有工作对照

| 已有工作 | 它做了什么 | 我们不同在哪 |
|---|---|---|
| DPR(Karpukhin) | 大语料上 dense vs BM25 对比,指标=top-k 准确率/EM | 我们:小库 + 章节级引用指标,且不加训练(用 bge-m3 零样本) |
| RAG(Lewis) | 端到端对比 learned/frozen/BM25,指标=EM/生成质量 | 我们:对比的是检索**配置**,不是端到端训练;北极星是双层引用正确率 |
| Survey(Gao) | 综述里定性讨论 hybrid/rerank | 我们:在小库上给**定量数据点** |
| Lost in the Middle(Liu) | 诊断位置效应、生成饱和早于召回 | 我们:把"少即是多/排序重要"变成**检索配置实验**(RQ3),并测引用正确率而非 accuracy |
| Verifiability(Liu) | 双层引用标准评估 4 个商业生成式搜索系统 | 我们:把双层标准用于**自有论文知识库 + 已知检索器**的 RAG,从而能归因检索 vs 生成(商业系统是黑盒,做不到) |
| Ragas(Es) | reference-free LLM-judge 自动评分 | 我们:以人工双层引用为金标准(更严格),Ragas 仅作自动化交叉参考 |
| RGB(Chen) | 四能力诊断基准(含负向拒答) | 我们:不造新基准,只把"负向拒答"落地为 answerable 标注 + 真/误拒答拆分 + 神谕消融 |
| CRUD-RAG(Lyu) | 中文基准,组件级评估 | 我们:用神谕检索做组件归因,而非新建基准/数据集 |
| CRAG(Yan) / HyDE / ColBERT / FiD | 纠错检索 / 零样本稠密 / 晚交互 / 多段落融合生成 | 作为知识库成员与评估题素材,非直接对比对象 |

## 3. 新颖性结论

- 🟢 **不新的部分(文献明确支持)**:双编码器检索、RRF 融合、Cross-Encoder 重排、双层引用标准、faithfulness 概念——全部有出处,本项目**不声称提出任何方法**。
- 🟡 **合理推断的新颖点**:上述组件的**组合方式**——"小规模领域知识库 + 论文/章节双层引用正确率 + 真/误拒答拆分 + 神谕检索归因"作为一个**实证研究设计**,在 12 篇文献范围内**未见直接重复**(已有工作要么是大语料+EM,要么是黑盒系统、无法归因)。
- 🔴 **尚未验证(这才是本项目要产出的事实)**:任何配置的胜负(哪个检索器更好)、章节感知切块是否提升章节级引用、Top-K 是否非单调——都是未知数,正是实验要回答的。

**一句话**:项目的"新"不在算法,而在——**在一个干净的小型、可归因、以溯源为第一指标的环境中,把检索配置的差异定量地报告出来**(含负结果)。

## 4. 防过度声称清单(写报告时逐条自检)

1. 任何"首个 / 第一次"表述 → 一律删除,除非有确切证据。
2. 方法层面的表述用"采用了(DPR 范式/RRF/Cross-Encoder/双层引用)",不用"提出"。
3. 每个结论绑定实验或文献;没有数据的结论不得进入摘要(对齐 plan Day 18 铁律)。
4. 负结果照常报告;被证伪的假设(H1~H4)同样是贡献。
5. 声称"该组合未见直接重复"必须基于 knowledge base 12 篇 + 综述覆盖范围,措辞用"在我们检索到的 12 篇范围内",不用"从未有人做过"。
